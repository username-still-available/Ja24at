# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2025-04-23

### Added
- Migrated project structure to use Eleventy static site generator.
- Content for main pages (Home, Impressum, Datenschutz) moved to Markdown files (`src/*.md`).
- Base Nunjucks layout created (`src/_includes/base.njk`) for shared HTML structure.
- Eleventy configuration file (`.eleventy.js`) added to manage build settings and passthrough static assets (CSS, JS, Fonts, Images).
- Global site data file (`src/_data/metadata.json`) created for metadata and structured data.
- `npm-run-all` dependency added for concurrent development tasks.
- `year` shortcode added to Eleventy config for dynamic copyright year.

### Changed
- Updated `package.json` build scripts (`build`, `start`) to integrate Tailwind CSS compilation and Eleventy build.
- Updated `netlify.toml` build settings (`publish` directory set to `_site`).
- Updated `js/process-steps.js` to ensure correct initialization.
- Corrected paths for Tailwind CSS input in `package.json`.
- Fixed JSON syntax errors in `src/_data/metadata.json`.
- Updated Nunjucks tag for the year shortcode in `src/_includes/base.njk`.

### Removed
- (Implicitly) Reliance on standalone HTML files (`index.html`, `impressum.html`, `datenschutz.html`) in the root directory for site structure. These will be generated by Eleventy into the `_site` directory.

## [0.1.0] - YYYY-MM-DD
- Initial project setup with static HTML, CSS, and basic JS.
- Tailwind CSS integrated for styling.
- Basic structure and content for Home, Impressum, Datenschutz pages.
- Netlify configuration added.

## [0.3.0] - 2025-04-24

### Added
- New images for the "Personenbetreuung" service section.
- Slideshow functionality for all three service sections (Kinderbetreuung, Begleitung, Personenbetreuung) using existing JavaScript.

### Changed
- Refactored `resize_images.sh` script to accept source and destination directory arguments for better flexibility.
- Processed new source images for "Personenbetreuung" using the updated `resize_images.sh` script, generating desktop and mobile versions (JPG and WebP).

### Fixed
- Resolved image loading errors by ensuring the Eleventy build process ran after image generation, copying assets to the `_site` directory.
